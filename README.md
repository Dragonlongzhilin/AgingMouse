# AgingMouse
Custom analysis scripts for profiling the epigenetic characteristics of aging mice using Paired-tag technology.

## Paired-Tag pipeline

The `Paired-Tag-Pipeline/` directory contains a copy of [scPT-Natural-Aging](https://github.com/7lagrange/scPT-Natural-Aging), authored by Hongjian Qi and included with the author's permission. The source snapshot corresponds to commit [`1a83f8ed015017c861e3acf74e9fe11f3f9943d3`](https://github.com/7lagrange/scPT-Natural-Aging/commit/1a83f8ed015017c861e3acf74e9fe11f3f9943d3). See the directory's README for pipeline documentation.
